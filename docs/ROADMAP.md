# Roadmap OpenCode Agentic Kit

Направления предварительные и отражают решения после разработки v0.8.2. Порядок и
состав задач могут меняться по результатам использования Kit в реальных проектах.

## v0.8.2 — исправления существующего workflow

Исправлены ротация TDD evidence при `/approve replace`, продолжение работы после
устаревания receipts, формат идентификаторов AC, а также ограниченные permissions
Developer для `git diff` и Runner `check`. Дополнительно усилены границы ролей
и безопасность разрешённых Git-команд; примеры в fenced code blocks исключены
из проверки AC ID.

## v0.9.0 — подготовка среды и удобство workflow

### Environment Setup — inspect и prepare

Разделить диагностику и подготовку окружения: `inspect` только сообщает о состоянии
Python, virtual environment, тестового toolchain и зависимостей; `prepare` предлагает
понятные действия по согласованию с пользователем. Не устанавливать зависимости
незаметно и не изменять окружение лишь ради диагностики.

### Организация `.agentic/`

Упорядочить хранение файлов задач и служебных материалов workflow, чтобы пользователю
было легче находить spec, plan, drafts и историю. Обеспечить совместимость с уже
созданными задачами и не нарушать внешнее состояние Runner.

### Расширенная проверка Acceptance Criteria

После уже реализованной проверки синтаксиса AC ID развить валидацию содержания:
проверяемость критериев, согласованность spec и plan, необходимые AC checks и
понятные сообщения о проблемах до реализации. Не превращать это в обязательную
процедуру для каждого функционального AC без оснований.

### Task UX и история

Улучшить отображение активной задачи, статусов, истории и результатов операций,
включая более прозрачные переходы между этапами workflow.

## Возможные направления без обязательств по версии

- Снижение стоимости Reviewer за счёт оптимизации контекста без потери независимой проверки.
- Ускорение простых задач. Отдельный lightweight workflow **не запланирован как
  обязательная функция**: дополнительный выбор режима может сделать процесс сложнее.

## v1.0.0 — первый стабильный релиз

Стабилизировать публичный интерфейс и совместимость после эксплуатации Kit в
нескольких независимых реальных проектах.

Roadmap не задаёт сроки и не является обещанием реализовать все направления.
